What it gets right: The macro strip answers "what's the market doing" in one glance. The treemap hero makes cashtag heat immediately scannable — NVDA's dominance at 847 mentions is visible without reading anything. The 3-column row below completes the State → Signal → Action narrative in one scroll.

Where it strains: The macro strip will overflow on smaller viewports. The 3-column widget row may feel cramped if widgets have variable-height content. The treemap needs a fallback for thin data (see stress test below).

Stress-test verdict: The treemap handles sparse data gracefully if you add an explicit "widen window" nudge inside the empty cells — the user immediately understands the cause and can act. The sentiment shift widget degrades cleanly to 2 rows + a fallback message. The calendar is fine because econ events are always present regardless of asset filter. The critical design decision is the minimum-mention threshold: expose it as a control (default 50 mentions), let the user lower it rather than just silently showing empty space.
