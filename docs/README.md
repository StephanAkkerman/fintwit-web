# Documentation Index

Use these files to track migration progress and integration status.

- `docs/migration-status.md`: what is implemented now, what is partially wired, and what is still missing.
- `docs/api-frontend-coverage.md`: backend API inventory, data source, payload summary, and frontend connection status.
- `docs/frontend-integration-map.md`: frontend component and hook map, including mounted vs unmounted features.

## Update Policy

When any API, service, hook, or UI feature changes, update these docs in the same change.
